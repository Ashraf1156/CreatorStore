.mvn  -> it is  like a npm registry from where all the dependencies will come and gets installed, when requested.

.gitignore -> used to make some files ignore by git.

mvnw/ -> this is the maven included in the project, gives us the flexibility not to install the maven separately, and it is at the project level.

src/main/ -> here you write all your buisness logic.
